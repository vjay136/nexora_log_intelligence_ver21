# NLI v22.10.0-0

- AI Resolution & Providers includes 15 hosted provider presets. Choose a suggested model or enter a custom model ID, then test the saved profile with your provider credentials.
- Automatic routing uses enabled profiles in priority order within the selected fallback group and request deadline. Exclusive default mode keeps requests on the selected profile.
- The gateway records provider fallback and displays a deduplicated warning when a standby profile answers.
- The release qualifies upgrades from v22.9.0-0.
